Agenda Math

Boundary: arithmetic only This page adds the times, durations and gaps you type, in whole minutes on a 24-hour clock. It does not say how long an item should take, whether a plan is realistic, or what anyone has agreed to.

The end truth

A start time plus a number of minutes. Past midnight is marked with the day.

The run truth

Start and end of every item in a running order. Durations go in a list in minutes, separated by commas.

The fit truth

A running order against the window it has to fit in. Gaps sit between items, not after the last one.

Agenda Math is exact arithmetic over the numbers you enter. Why it exists.
